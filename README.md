# Snake

This is a small Snake game written in plain JavaScript with no dependencies.
The game rules live in `src/snake.js`, and the browser code lives in `src/main.js`.
Run `npm test` to execute the tests with Node.js 22 or later.
Open `index.html` in a browser to play.
Use the arrow keys (Up, Down, Left, Right) to steer the snake.
Sandbox ship check for FL-316.
