Review the change held in the Workspace against what the Work Item asked for, and
report one verdict.

Approve when the change does what the Work Item asked and nothing in it needs to be
different before someone else can rely on it. Request changes when one thing has to be
different first, and name that one thing: the file or symbol it lives at, how serious it
is, and what a reader has to understand to judge it.

Request changes for at most one thing. A second concern belongs in a later pass, because
the whole point of this verdict is to send exactly one instruction onward. Rank a concern
as a blocker when relying on the change would be wrong until it is fixed, as technical
debt when it will cost someone later without being wrong now, and as skippable when it
is a preference you would not defend.

Judge only the change and the request it answers. Do not rewrite the change yourself and
do not review anything the change did not touch.
